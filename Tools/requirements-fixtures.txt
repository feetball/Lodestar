# Install into an isolated environment (hash-checking mode rejects anything that does not match):
#
#   python3 -m venv --system-site-packages .venv-fixtures
#   .venv-fixtures/bin/pip install --require-hashes -r Tools/requirements-fixtures.txt
#
# Every distribution is pinned to an exact version and to the SHA-256 digests of its pure-Python
# wheel and its source archive, copied from https://pypi.org/pypi/<name>/<version>/json.
# (sgp4 also publishes compiled wheels; only the pure-Python wheel is allowed here, so that every run propagates
# satellites with the same code. The satellite scripts do propagate: `passes` and `streaks` of
# make_satellite_fixtures.py and make_satellite_transit_reference.py call sgp4 through Skyfield's EarthSatellite.)
#
# numpy (required by Skyfield and jplephem, and imported directly by make_fixtures.py,

# wheels are platform specific, and the fixtures do not depend on its version.
# Install it first from the system package manager or with `pip install numpy`.
#
# Pillow (9.1 or newer; make_app_icon.py and review/night_leaks.py, not the fixtures) is not listed either: it has
# no pure-Python wheel, so it cannot be pinned by hash in this file. Install it with `pip install "Pillow>=9.1"`.
